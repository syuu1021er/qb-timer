使い方

1. ユーザーを選ぶ

一番上の「ユーザー」で自分の名前（しゅういちろう・ともや・ひろし）を押します。記録・設定・グラフは人ごとに別々です。次に開いたときは、その端末で最後に選んだ人になっています。

2. 時間を決める

「解く」は1問を解く目標時間、「解説」は解説を読む目標時間です。−10+10で10秒ずつ、右のボタンで一発設定できます。

3. 計る

  1. 真ん中の大きい画面をタップ（PCはスペースキー）でスタート。
  2. 解き終わったらタップ → 「解説」に切り替わります。
  3. 解説を読み終わったらタップ → 次の問題の「解く」が始まります。

残り10秒で黄色、時間を過ぎると赤になり「+0:12」のように超過時間を数えます（止まりません）。「音 オン」にすると時間切れで音が鳴ります。休憩は「一時停止」（PCは P）。

4. 記録を見る

  • 今日 ○問・今日の演習時間：その日の合計（解く＋解説）。
  • この回：ページを開いてから（または「この回をリセット」してから）の問題数と時間。
  • 今日の解く平均・解説平均：その日に解いた全問題の平均。
  • 解く時間オーバー：この回で目標時間を超えた問題の数。
  • 下の小さな箱は1問ごとの「解く／解説」の時間、棒グラフは直近14日の問題数です（棒にカーソルを合わせると演習時間も出ます）。

5. PCとiPadで同期する

何もしなくても、ネットにつながっていればPC・iPad・スマホのどれでも自動で同期されます。どの端末でも自分の名前を選ぶだけでOK。右下に「PCとiPadで同期中」と出ていれば同期できています。

6. 記録の引き継ぎ

「記録の引き継ぎ」で、全員分の記録を文字にして書き出し、別の場所（claude.ai版 ⇄ GitHub Pages版）に読み込めます。同じ日の記録は問題数の多いほうが残ります。

こまかいこと

  • 画面は計測中スリープしにくくなります（対応ブラウザのみ）。
  • 同期していないときは、そのブラウザだけに保存されます。履歴・サイトデータを消すと記録も消えます。

記録の引き継ぎ

書き出す（引き継ぎ元で）

3人分の記録と設定をまとめた文字を作ります。全部コピーして、引き継ぎ先に貼ってください。

読み込む（引き継ぎ先で）

読み込んだ記録は、同期中ならほかの端末にも反映されます。
